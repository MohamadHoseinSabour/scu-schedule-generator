# 🎓 SCU Schedule Generator (ربات تلگرام برنامه هفتگی دانشگاه)

یک سیستم کامل و ماژولار پایتونی برای پردازش گزارش‌های انتخاب واحد دانشگاه شهید چمران اهواز (`Report.xls` / `.xlsx`)، نرمال‌سازی داده‌ها، و تبدیل خودکار آن‌ها به برنامه هفتگی تمیز، زیبا و بدون نقص در دو فرمت **HTML واکنش‌گرا (مستقل از اینترنت)** و **تصویر باکیفیت PNG**.

---

## 📌 ویژگی‌های کلیدی پروژه

- **✅ پردازش قطعی و Rule-Based (بدون هوش مصنوعی):** استخراج دقیق داده‌ها از اکسل‌های چندسطحی با سلول‌های ادغام‌شده (Merged Cells) بر اساس قوانین ساختاری و نرمال‌سازی ارقام فارسی/عربی.
- **✅ مدل داده کانونی (Canonical Model):** تمامی خروجی‌ها از یک مدل واحد (`ScheduleReport`) تغذیه می‌شوند تا هیچ اختلافی بین HTML و عکس وجود نداشته باشد.
- **✅ رابط کاربری تلگرام (Aiogram 3):** کیبوردهای تعاملی، سیستم آپلود، دکمه‌های شیشه‌ای، بازخورد پیشرفت کاربر، و مدیریت خطا بدون نمایش لاگ‌های فنی به دانشجو.
- **✅ رندرینگ آفلاین HTML:** استفاده از قالب Jinja2 با استایل‌های RTL و فونت فارسی وزیرمتن به صورت کاملاً مستقل از CDN اینترنتی.
- **✅ تولید تصویر با Playwright:** تولید اسکرین‌شات Retina با ابعاد مناسب موبایل و بدون نمایش روزهای پنجشنبه و جمعه یا متون نامربوط در سلول‌های خالی.
- **✅ پنل مدیریت و آمار (FastAPI):** رهگیری نرخ تبدیل، شمارش کاربران، رصد سلامت سرویس‌ها و تفکیک کلیک‌های اشتراک‌گذاری (Share) از ورودی‌های واقعی دعوت (Referral Deep Link).
- **✅ آماده برای فاز ۲ (ورود به سامانه دانشگاه):** معماری تفکیک‌شده آداپتور پورتال به همراه Feature Flag (`PORTAL_ENABLED=false`) بدون ذخیره‌سازی هیچ‌گونه پسورد یا اطلاعات حساس.

## 🚀 راهنمای نصب و راه‌اندازی سریع

### ۱. پیش‌نیازها
- Python 3.12 یا بالاتر
- Git
- Playwright Chromium (`playwright install chromium`)
- Redis و PostgreSQL (یا SQLite برای توسعه محلی)

### ۲. نصب به صورت محلی (Local Development)

```bash
# کلون کردن ریپازیتوری
git clone https://github.com/MohamadHoseinSabour/scu-schedule-generator.git
cd scu-schedule-generator

# ایجاد محیط مجازی
python -m venv venv
venv\Scripts\activate      # در ویندوز
# source venv/bin/activate # در لینوکس / مک

# نصب پیش‌نیازها
pip install -r requirements.txt

# نصب مرورگر Playwright
playwright install chromium

# کپی فایل تنظیمات
cp .env.example .env
```

فایل `.env` را باز کرده و توکن ربات (`BOT_TOKEN`) خود را از BotFather وارد نمایید:
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
BOT_USERNAME=YourScheduleBot
ADMIN_TELEGRAM_IDS=123456789
```

### ۳. اجرای ربات
```bash
python -m app.main
```

### ۴. اجرای پنل ادمین
```bash
uvicorn app.admin.routes:app --reload --port 8000
```
داشبورد مدیریت در آدرس `http://localhost:8000/admin` در دسترس خواهد بود (نیاز به هدر `X-Admin-ID`).

## 🐳 استقرار با داکر (Docker Compose)

کل بسته شامل ربات تلگرام، وب‌سرویس ادمین، ورکر Celery، دیتابیس PostgreSQL و کش Redis با یک فرمان قابل راه‌اندازی است:

```bash
docker-compose up -d --build
```

سرویس‌های اجرا شده:
- `scu_bot`: پردازش‌کننده پیام‌ها و آپلودهای تلگرام
- `scu_admin_api`: وب‌سرور پنل ادمین و بررسی سلامت (پورت 8000)
- `scu_worker`: پردازش کارهای سنگین و پاکسازی دوره‌ای فایل‌ها
- `scu_postgres`: ذخیره‌سازی دائمی اطلاعات کاربران و جاب‌ها
- `scu_redis`: صف پیام و کش محدودسازی نرخ درخواست (Rate Limit)

### آزمون نمونه طلایی (Golden Test)
فایل `ReferenceS/Report.xls` به عنوان ورودی معیار سنجیده می‌شود و تضمین می‌کند:
- تعداد دروس دقیقاً ۹ درس است.
- مجموع واحدها دقیقاً ۲۰.۰ است.
- روزهای پنجشنبه و جمعه از خروجی تصویر حذف شده‌اند.
- هیچ متنی با عنوان «آزاد» در تصویر نهایی تولید نمی‌شود.

## 🛡️ اصول امنیتی و حریم خصوصی

1. **عدم ذخیره رمز عبور:** هیچ فیلدی برای ذخیره پسورد در دیتابیس وجود ندارد و در آینده نیز ورود به سامانه دانشگاه فقط به صورت درون‌حافظه‌ای و موقت خواهد بود.
2. **چرخه حیات فایل‌ها:** فایل‌های موقت آپلود شده پس از اتمام پردازش فوراً پاک می‌شوند. فایل‌های خروجی دارای TTL معین (پیش‌فرض ۲۴ ساعت) هستند و توسط ورکر پس‌زمینه پاکسازی می‌گردند.
3. **محدودسازی نرخ (Rate Limiting):** جلوگیری از ارسال انبوه فایل توسط ربات با استفاده از مکانیزم پنجره لغزان در Redis.
